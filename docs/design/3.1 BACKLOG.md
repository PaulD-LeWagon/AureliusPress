## P2: Medium Priority

1. **Bulk Operations UI:** Admin controllers have no `bulk_edit`/`bulk_update` implementation. Multiple feature specs are marked `skip "Implement bulk actions scenario"`. This is a feature epic requiring checkbox UI, controller actions, and Turbo Stream responses across documents, authors, and users. Minimum 8 pts — plan as its own sprint.
2. **Devise Email Confirmation:** 3 routing specs are `skip "Not yet implemented"` for confirmations. Enabling `confirmable` requires a migration (adding `confirmation_token`, `confirmed_at`, `confirmation_sent_at` columns) and changes to the auth flow. Plan as a dedicated sprint when email infrastructure is ready.
3. **Turbo Polish — Admin fragment moderation (DEFER-1 from audit):** `admin/fragment/comments#destroy` and `admin/fragment/notes#destroy` currently redirect after soft-delete. Add Turbo Stream row removal so moderators can discard without losing scroll position. ~2 pts.
4. **Turbo Polish — Admin index row removal (DEFER-2 from audit):** All admin index delete links (authors, sources, quotes, tags, categories, users) do a full-page redirect. Add Turbo Stream `<tr>` removal per row. Requires `dom_id`-scoped `<tr>` wrappers on each index table. ~5 pts.
5. **Turbo Polish — Public document index card removal (DEFER-3 from audit):** Public `destroy` on blog posts, pages, and journal entries redirects to the index list. Add Turbo Stream card/row removal. ~3 pts.

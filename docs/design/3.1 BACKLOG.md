1. **Bulk Operations UI:** Admin controllers have no `bulk_edit`/`bulk_update` implementation. Multiple feature specs are marked `skip "Implement bulk actions scenario"`. This is a feature epic requiring checkbox UI, controller actions, and Turbo Stream responses across documents, authors, and users. Minimum 8 pts — plan as its own sprint.
2. **Devise Email Confirmation:** 3 routing specs are `skip "Not yet implemented"` for confirmations. Enabling `confirmable` requires a migration (adding `confirmation_token`, `confirmed_at`, `confirmation_sent_at` columns) and changes to the auth flow. Plan as a dedicated sprint when email infrastructure is ready.

Noticed during Sprint 10 Turbo polish work. Low risk today (admin-only routes, role guard on controller) but should be corrected for consistency with the rest of the admin namespace.

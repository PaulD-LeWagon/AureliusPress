# 2.2 Tech Stack

## Core
- **Framework:** Ruby on Rails (7.2.2)
- **Language:** Ruby (via `.ruby-version`, likely 3.3+)
- **Database:** PostgreSQL (pg ~> 1.6)

## Frontend
- **Asset Management:** `importmap-rails` for JS, `cssbundling-rails` + Sass for CSS, `sprockets-rails`.
- **Javascript/SPA:** Hotwire stack (`turbo-rails`, `stimulus-rails`).
- **Styling:** `@picocss/pico` (classless/minimal CSS framework) + Autoprefixer + FontAwesome.
- **Rich Text:** ActionText + Trix editor.

## Authentication & Authorization
- **Auth:** Devise (users, passwords, sessions)
- **Authorization:** Pundit (role-based/policy-based access control)

## Tooling & Utilities
- **Pagination:** `pagy`
- **Soft Deletion:** `discard` (applied to Fragments)
- **File Uploads:** ActiveStorage + `image_processing`

## Testing
- **Framework:** RSpec (`rspec-rails`)
- **System/Feature Tests:** Capybara (driver abstraction) · Selenium (WebDriver protocol) · Cuprite (headless Chrome via CDP — default driver)
- **Fixtures/Mocks:** `factory_bot_rails`, `faker`
- **Other:** `shoulda-matchers`, `simplecov` (coverage), `parallel_tests`
- **Spec layers:** `spec/models`, `spec/policies`, `spec/controllers`, `spec/requests`, `spec/features`, `spec/routing`

## Quality & Code Standard
- **Linter:** RuboCop (`rubocop-rails-omakase`, `rubocop-rspec`)
- **Security:** Brakeman

# 3.4 Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [Sprint 10] - 2026-05-09
### Changed
- Admin fragment moderation (`comments#destroy`, `notes#destroy`) now responds with Turbo Stream row removal; `dom_id` added to index `<tr>` rows.
- All 6 admin index table destroy actions (authors, sources, quotes, tags, categories, users) respond with Turbo Stream `<tr>` removal; `dom_id` wrappers added to all index tables.
- Public document destroy actions (blog posts, pages, journal entries) respond with Turbo Stream row removal; `dom_id` wrappers added to public index tables.
- 9 feature specs updated to assert DOM removal / DB state instead of redirect flash messages, reflecting the new inline Turbo Stream delete UX.
### Fixed
- Missing `authorize @note` in `admin/fragment/notes#destroy` — security omission silently present since notes controller was written.

## [Sprint 9] - 2026-05-09
### Added
- `AureliusPress::Admin::Document::ContentBlocksController` with `destroy` action + Turbo Stream template.
- `AureliusPress::Document::ContentBlocksController` with `destroy` action + Turbo Stream template.
- Request specs for ContentBlock `DELETE` across admin blog posts, admin pages, public blog posts, and public pages.
- `community/reactions/destroy.turbo_stream.erb` — Reactions `destroy` now responds with a Turbo Stream replacing the engagement bar frame (consistent with Likes).
- `docs/design/TURBO-AUDIT.md` — full audit of every CRUD endpoint; classifies Turbo Stream vs. full-page redirect; catalogues gaps and deferrable improvements.
### Changed
- `_content_block_fields.html.erb` Remove button: persisted ContentBlocks now use a Turbo delete link; new (unsaved) blocks retain the Stimulus `nested-forms#remove` button.
- `ReactionsController#destroy` updated to `respond_to` with `turbo_stream` format.
### Fixed
- Removed `execute_script` workaround from all 4 ContentBlock management feature specs — DELETE scenarios now verify proper Turbo Stream DOM removal.
- `admin/community/likes/index.html.erb` delete link: replaced legacy `method: :delete` (Rails UJS, broken in Rails 7) with `data: { turbo_method: :delete, turbo_confirm: ... }`.

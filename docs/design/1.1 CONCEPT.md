# 1.1 Concept

## The Problem
AureliusPress is built to solve the need for a minimalist, highly structured, and aesthetically distinct digital publishing platform. Existing content management systems (CMS) often suffer from feature bloat, complex thematic layers, and inefficient categorization. 

## The Solution
AureliusPress is a Stoic-inspired CMS designed for authors who value structure and clarity. It combines a robust core engine (Ruby on Rails) with a premium visual philosophy (Tyrian Purple, high contrast, PicoCSS). 

Key differentiators include:
- **Polymorphic Content Structure:** Beyond simple posts, the platform supports highly composable content blocks (text, image, gallery, video) nested within various document types (Blog Posts, Pages, Atomic Blog Posts).
- **Stoic Catalogue System:** Built-in models for Authors, Sources (Books), and Quotes.
- **Advanced Taxonomy:** A Hotwire-powered search-select taxonomy component allowing for rapid, on-the-fly categorization and tagging.
- **Community & Engagement:** Distinct lines between public anonymous reading and registered community interaction (Groups, Reactions, Likes, and nested Comments/Notes).

# 2.4 Data Model

The data model makes heavy use of Polymorphism and Single Table Inheritance (STI).

## Core Entities

### Users & Community
- **`aurelius_press_users`**: Devise authenticated users. Includes role, status, age, first/last name, and `username`.
- **`aurelius_press_groups`**: User-created groups with privacy settings.
- **`aurelius_press_group_memberships`**: Join table for Users & Groups (with role, status, and optional `invited_by_id`).

### Documents (STI)
- **`aurelius_press_documents`**: Base table for documents (STI). Types include Blog Posts, Pages, Atomic Blog Posts, and Journal Entries. Includes visibility, status, slug, and `comments_enabled`.
- **`aurelius_press_documents_aurelius_press_groups`**: Many-to-many join table linking Documents to Groups (enables group-scoped document visibility).

### Content Blocks (Polymorphic)
- **`aurelius_press_content_blocks`**: Belongs to a Document and is polymorphic (`contentable`). Manages position, `html_id`, and `data_attributes`.
- Block specific types (not STI, distinct tables):
  - `aurelius_press_gallery_blocks`
  - `aurelius_press_image_blocks`
  - `aurelius_press_rich_text_blocks`
  - `aurelius_press_video_embed_blocks`

### Catalogue
- **`aurelius_press_authors`**: Name, slug, bio, birth/death dates.
- **`aurelius_press_sources`**: Books/materials. Title, description, date, ISBN.
- **`aurelius_press_quotes`**: Quotes from Sources. Belongs to Source, can reference `original_quote_id`.
- **`aurelius_press_authorships`**: Join table for Authors & Sources.

### Engagement & Taxonomy
- **`aurelius_press_fragments`**: STI table for `Comments` and `Notes`. Polymorphic associations (`commentable`, `notable`) linking them to Documents, ContentBlocks, or Catalogue items. Uses soft-delete (`discarded_at`).
- **`aurelius_press_likes`**: Polymorphic `likeable` (state: like/unlike).
- **`aurelius_press_reactions`**: Polymorphic `reactable` with emoji tracking.
- **`aurelius_press_tags`** / **`aurelius_press_categories`**: Taxonomy with join tables (`taggings`, `categorizations`) for polymorphic tagging of various models.
- **`aurelius_press_affiliate_links`**: Polymorphic links for monetisation.

### Admin & Configuration
- **`aurelius_press_site_settings`**: Key-value store for admin-configurable site settings (key, value, value_type, description). Supports string, boolean, integer, and other typed values. Managed via the admin settings UI.

## File Attachments & Rich Text
- **ActionText**: `action_text_rich_texts` table for rich text content.
- **ActiveStorage**: Blobs, Attachments, and VariantRecords.

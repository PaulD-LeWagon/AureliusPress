# 1.4 Product Requirements Document (PRD)

## 1. Executive Summary
AureliusPress is a minimalist, Stoic-inspired content management system (CMS) and digital publishing platform. It serves both as a traditional CMS for publishing structured documents and a catalogue system for tracking authors, books (sources), and quotes.

## 2. Functional Requirements

### 2.1 Content Management (CMS)
- **Document Types:** Support for Standard Blog Posts, Atomic Blog Posts, Pages, and Private Journal Entries.
- **Content Blocks:** Documents are constructed using nested, orderable blocks (Rich Text, Images, Galleries, Videos).
- **Soft Deletion:** Fragments (Comments, Notes) use soft-deletion to preserve audit trails while hiding content from public views.
- **Site Settings:** An admin panel backed by a key-value store to manage global configuration.

### 2.2 Taxonomy & Catalogue
- **Catalogue Elements:** Dedicated management for Authors, Sources, and Quotes.
- **Hotwire Taxonomy UX:** Search-as-you-type mechanism for assigning Tags and Categories to content, including on-the-fly creation via Stimulus/Turbo.
- **API Access:** An internal V1 API to support the Hotwire taxonomy search, and a public V1 API providing paginated JSON endpoints for Quotes.

### 2.3 Community & Engagement
- **Engagement Mechanisms:** Polymorphic Likes and emoji Reactions on both Documents and Catalogue items.
- **Comments & Notes:** Ability for users to leave public comments or private notes.
- **Groups:** Support for public/private Groups and group memberships.

### 2.4 JavaScript Testing Infrastructure
- **JS Suite:** A dedicated Vitest infrastructure (`spec/javascript`) utilizing JSDOM to test Stimulus controllers in isolation without full browser boot overhead.

## 3. Non-Functional Requirements
- **Performance:** Initial server response under 150ms. High utilization of Turbo Streams for DOM updates without full page reloads.
- **Testing:** 100% RSpec Test Suite coverage required for all Catalogue models, Policies, and core workflows.
- **Aesthetics:** A "premium", high-contrast design using PicoCSS extended with a custom Tyrian Purple theme.

## 4. Definition of Done (Overall System)
- Complete RSpec green status (>1200 examples passing).
- Complete Vitest suite green status for JavaScript controllers.
- Strict Pundit authorization covering all controllers.

# 3.3 Definition of Done

A story, feature, or bug fix is only considered "Done" when it meets all the following criteria:

## Code & Quality
1. **Code Complete:** The implementation satisfies all acceptance criteria listed in the sprint backlog.
2. **Linting:** Zero RuboCop offences (`bundle exec rubocop`).
3. **Security:** Zero Brakeman vulnerabilities (`bundle exec brakeman`).

## Testing
1. **RSpec Suite Green:** All tests pass locally (`bundle exec rspec`).
2. **JavaScript Tests Green:** All Vitest tests pass locally (`yarn test`).
3. **No Coverage Drops:** SimpleCov reports branch/line coverage remains above the agreed project threshold (80%+).

## Integration & Deployment
1. **CI Passed:** GitHub Actions pipeline passes all checks (Tests + Linting + Security) on the Pull Request.
2. **No Visual Regressions:** Hotwire/Turbo Stream updates work seamlessly in the browser without requiring a hard refresh.
3. **Clean Migration:** Any database migrations have been tested against a realistic dataset (`rails db:migrate:redo`).
